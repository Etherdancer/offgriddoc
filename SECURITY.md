# Security policy

OffGridDoc handles sensitive documents, so redaction bugs are treated as security issues —
for example, text that survives export, or data sent off the device.

**Please report vulnerabilities privately** using GitHub's
[private vulnerability reporting](https://github.com/Etherdancer/offgriddoc/security/advisories/new)
rather than a public issue. Include steps to reproduce and, if possible, a sample file
(with no real personal data).

Only the latest release deployed at https://offgriddoc.pages.dev/ is supported.
